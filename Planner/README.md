# Life Planner

Life Planner is an iOS application designed to help university students organise their daily life, including study plans, fitness schedules, goals, reminders, and workout progress tracking.

# Features

- Create daily tasks
- Timetable-style schedule view
- Study / Fitness / Goals / Reminder categories
- Custom categories
- Task priority selection
- Daily task summary
- Workout record tracking
- Fitness progress line charts

---

# Frameworks Used

- SwiftUI
- Charts Framework
- UserDefaults
- NavigationStack
- TabView

---

# Problem Being Solved

University students often struggle to manage:
- Study schedules
- Fitness plans
- Personal goals
- Daily reminders

Life Planner combines these activities into one simple timetable-based application.

---

# Innovation Feature

## Fitness Progress Tracking

Users can:
- Record exercise name
- Record weight and sets
- Save workout history
- Generate line charts for exercise progress
- Switch between different exercises
